# 💰 MagPro AdSense Setup Guide

Complete guide to configure Google AdSense with MagPro theme in minutes.

## ⚡ Quick Setup (5 Minutes)

### Step 1: Get Your Publisher ID
1. Go to [Google AdSense](https://adsense.google.com)
2. Click **Account** → **Account information**
3. Find your **Publisher ID** (format: `ca-pub-1234567890123456`)
4. Copy it

### Step 2: Configure in WordPress
1. Login to WordPress admin
2. Go to **Appearance** → **Customize**
3. Open **MagPro Settings** → **AdSense / Ads**
4. Paste your Publisher ID in the first field

### Step 3: Enable Auto Ads (Recommended)
- Check "🤖 Enable AdSense Auto Ads"
- Save & Publish
- ✅ Done! Auto ads will start displaying within 1 hour

**OR** use Manual Placements (see below)

## 🔑 Getting Slot IDs from AdSense

### For Auto Ads
- AdSense handles everything automatically
- No Slot IDs needed
- Google optimizes placement and sizing

### For Manual Ads
1. Go to [AdSense](https://adsense.google.com)
2. Click **Ads** → **By placement**
3. Click **New ad placement**
4. Enter a name (e.g., "Header Banner")
5. Select size (e.g., 728x90)
6. Click **Create**
7. Copy the **Slot ID** shown (format: `1234567890`)
8. Paste in WordPress Customizer

## 🆘 Troubleshooting

### Ads Not Showing

**Check 1: Publisher ID**
```
Customizer → AdSense / Ads
→ Is Publisher ID filled in?
→ Format correct: ca-pub-XXXXX?
```

**Check 2: Slot IDs**
```
For each enabled placement:
→ Is Slot ID filled in?
→ Format correct: numbers only?
→ Copy-pasted exactly from AdSense?
```

**Check 3: Placement Enabled**
```
Each placement must have:
☑️ Checkbox enabled
☑️ Slot ID filled
→ Then Save & Publish
```

**Check 4: Wait 24 Hours**
```
New placements take up to 24 hours
to appear. Be patient!
```

**Check 5: AdSense Account Status**
```
AdSense Dashboard
→ Account → Account status
→ Is it "Active"?
→ Any warnings/violations?
```
